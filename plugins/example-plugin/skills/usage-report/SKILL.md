# 文本字数统计与使用报告

## 目标

对用户给定的文本完成字数统计，并按固定模板输出一份简短的使用报告。

- 核心目标：统计结果必须来自 `word_count` 工具的真实返回值，禁止自行估算。
- 关键成功条件：报告包含字符数、非空字符数、单词数、行数四项指标，且与工具返回一致。

## 工作流

1. 向用户确认待统计文本；若用户消息中已给出文本则直接使用。
2. 调用 `word_count` 工具，入参 `text` 为完整待统计文本。
3. 检查返回值：`success=false` 时向用户说明错误原因并停止；`success=true` 时进入第 4 步。
4. 按以下模板输出报告：

```
## 文本统计报告

- 字符数：{characters}
- 非空字符数：{characters_no_spaces}
- 单词数：{words}
- 行数：{lines}
```

## 验收标准

- 四项指标逐项列出，数值与工具返回值完全一致。
- 不引入工具返回值之外的臆造字段。
